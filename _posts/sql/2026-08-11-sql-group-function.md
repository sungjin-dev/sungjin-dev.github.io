GROUP BY는 데이터를 그룹으로 나눠 집계하는 기본 문법이지만, 실무에서는 한 번의 쿼리로 여러 수준의 소계를 동시에 구해야 할 때가 많다. 그럴 때 쓰는 게 바로 ROLLUP, CUBE, GROUPING SETS, GROUPING 함수들이다. SQLD 시험에도 자주 나오니 이번 기회에 정리해두자.

---

## ROLLUP — 계층적 소계

#### 개념
GROUP BY ROLLUP(A, B)를 쓰면 A와 B로 그룹화한 결과 외에도, A만으로 그룹화한 소계, 그리고 전체 합계까지 한 번에 나온다. **순서가 매우 중요하다.** 앞에 있는 컬럼이 상위 개념이다.

#### 결과 구조
예를 들어 ROLLUP(부서, 직급)을 쓰면 다음 4가지 그룹이 나온다:
- (부서, 직급) 별 세부 집계
- (부서) 별 소계 (모든 직급 합친 것)
- () 전체 총합 (모든 부서 합친 것)

#### SQL 예시

```sql
SELECT 부서, 직급, COUNT(*) AS 인원수, SUM(급여) AS 급여합
FROM 직원
GROUP BY ROLLUP(부서, 직급)
ORDER BY 부서, 직급;
```

**결과:**
| 부서 | 직급 | 인원수 | 급여합 |
|------|------|--------|--------|
| 영업 | 과장 | 5 | 250,000 |
| 영업 | 대리 | 3 | 180,000 |
| 영업 | NULL | 8 | 430,000 | ← 영업 부서 소계
| 개발 | 과장 | 4 | 200,000 |
| 개발 | 대리 | 6 | 320,000 |
| 개발 | NULL | 10 | 520,000 | ← 개발 부서 소계
| NULL | NULL | 18 | 950,000 | ← 전체 총합

#### 핵심 특징
- ROLLUP(A, B, C)의 그룹 개수 = **N + 1개** → 4개 그룹 생김
  - (A, B, C), (A, B), (A), ()
- 계층 구조가 명확하고, 위에서 아래로 차수를 줄여나감
- ROLLUP(부서, 직급)과 ROLLUP(직급, 부서)의 결과는 다르다
- B 기준 소계(직급별 전체 합)는 나오지 않음

## CUBE — 모든 조합의 소계

#### 개념
CUBE는 지정한 모든 컬럼의 조합 가능한 경우의 수를 전부 구한다. 가능한 모든 각도에서 집계를 본다고 생각하면 된다.

#### 결과 구조
CUBE(A, B)를 쓰면 다음 4가지 그룹이 나온다:
- (A, B) 별 세부 집계
- (A) 별 소계
- (B) 별 소계 ← ROLLUP에는 없는 것!
- () 전체 총합

#### SQL 예시

```sql
SELECT 부서, 직급, COUNT(*) AS 인원수, SUM(급여) AS 급여합
FROM 직원
GROUP BY CUBE(부서, 직급)
ORDER BY 부서, 직급;
```

**결과 (일부):**
| 부서 | 직급 | 인원수 | 급여합 |
|------|------|--------|--------|
| 영업 | 과장 | 5 | 250,000 |
| 영업 | 대리 | 3 | 180,000 |
| 영업 | NULL | 8 | 430,000 | ← 영업 부서 소계
| 개발 | 과장 | 4 | 200,000 |
| 개발 | 대리 | 6 | 320,000 |
| 개발 | NULL | 10 | 520,000 | ← 개발 부서 소계
| NULL | 과장 | 9 | 450,000 | ← 과장 직급 소계 (ROLLUP엔 없음!)
| NULL | 대리 | 9 | 500,000 | ← 대리 직급 소계 (ROLLUP엔 없음!)
| NULL | NULL | 18 | 950,000 | ← 전체 총합

#### 핵심 특징
- CUBE(A, B, C)의 그룹 개수 = **2^N개** → 2³ = 8개 그룹 생김
- 각 컬럼마다 독립적으로 소계가 나옴
- 순서는 상관없다 (ROLLUP과 달리!)
- 다차원 분석이나 BI 대시보드에서 유용함

## GROUPING SETS — 지정한 그룹만 집계

#### 개념
GROUPING SETS를 쓰면 "이 그룹과 저 그룹만 구하겠다"고 명시할 수 있다. 모든 조합을 구하는 게 아니라, 필요한 것만 골라서 계산한다.

#### 결과 구조
GROUPING SETS((A), (B))를 쓰면 다음 2가지 그룹만 나온다:
- (A) 별 소계
- (B) 별 소계
- 전체 총합 () 은 자동으로 추가됨

#### SQL 예시

```sql
SELECT 부서, 직급, COUNT(*) AS 인원수, SUM(급여) AS 급여합
FROM 직원
GROUP BY GROUPING SETS((부서), (직급))
ORDER BY 부서, 직급;
```

**결과:**
| 부서 | 직급 | 인원수 | 급여합 |
|------|------|--------|--------|
| 영업 | NULL | 8 | 430,000 |
| 개발 | NULL | 10 | 520,000 |
| NULL | 과장 | 9 | 450,000 |
| NULL | 대리 | 9 | 500,000 |

#### 핵심 특징
- 지정한 그룹만 구함 (CUBE처럼 모든 조합을 구하지 않음)
- GROUPING SETS((A), (B), (A,B))로 원하는 조합만 명시 가능
- GROUPING SETS()를 넣으면 전체 합도 함께 나옴
- 필요한 것만 계산하므로 가장 효율적일 수도 있음

## GROUPING() — 소계 행 판별 함수

#### 개념
ROLLUP이나 CUBE를 쓰면 소계와 총합 계산 때문에 결과에 NULL 값이 생긴다. 이 NULL이 "원래 데이터가 NULL인 건지, 아니면 소계 때문에 생긴 NULL인지" 구분하는 함수다.

#### 출력값
- **0** : 해당 컬럼이 정식으로 그룹화되어 집계에 사용된 것 (일반 데이터 행)
- **1** : 해당 컬럼이 소계/합계 계산으로 인해 NULL인 것 (소계 행)

#### SQL 예시

```sql
SELECT 
    CASE WHEN GROUPING(부서) = 1 THEN '전체' ELSE 부서 END AS 부서,
    CASE WHEN GROUPING(직급) = 1 THEN '소계' ELSE 직급 END AS 직급,
    COUNT(*) AS 인원수,
    SUM(급여) AS 급여합
FROM 직원
GROUP BY ROLLUP(부서, 직급)
ORDER BY 부서, 직급;
```

**결과:**
| 부서 | 직급 | 인원수 | 급여합 |
|------|------|--------|--------|
| 영업 | 과장 | 5 | 250,000 |
| 영업 | 대리 | 3 | 180,000 |
| 영업 | 소계 | 8 | 430,000 |
| 개발 | 과장 | 4 | 200,000 |
| 개발 | 대리 | 6 | 320,000 |
| 개발 | 소계 | 10 | 520,000 |
| 전체 | 소계 | 18 | 950,000 |

#### 핵심 특징
- GROUPING(컬럼) 형태로 사용
- CASE 문과 함께 쓸 때 진가를 발휘함
- 보고서나 BI에서 소계/합계 행을 명확히 표시할 때 필수적
- 원래 NULL과 소계로 인한 NULL을 구분 가능

## 비교표로 한눈에 정리

| 함수 | 결과 그룹 | 계층 구조 | 순서 중요 | 사용 시기 |
|------|---------|---------|---------|---------|
| **ROLLUP(A,B)** | (A,B), (A), () | 있음 | 매우 중요 | 상위/하위 계층 분석 |
| **CUBE(A,B)** | (A,B), (A), (B), () | 없음 | 상관없음 | 다차원 분석 |
| **GROUPING SETS** | 지정한 것만 | 없음 | 상관없음 | 선택적 집계 |
| **GROUPING()** | 0 또는 1 | - | - | NULL 판별 |

## SQLD 시험 암기 팁

#### 그룹 개수 공식
- ROLLUP(A, B, C) = 4개 → **N + 1**
- CUBE(A, B, C) = 8개 → **2^N**
- GROUPING SETS는 명시한 개수 = **자유**

#### 단골 시험 패턴
```sql
SELECT 
    CASE WHEN GROUPING(컬럼) = 1 THEN '총합계' ELSE 컬럼 END,
    ...
FROM 테이블
GROUP BY ROLLUP(컬럼1, 컬럼2);
```
이 형태가 거의 매번 출제된다. GROUPING()으로 소계 행을 판별해서 이름을 붙이는 패턴은 필수 암기.

#### 헷갈리기 쉬운 부분
- ROLLUP(부서, 직급)은 **"직급 기준 소계는 나오지 않는다."**
- CUBE는 모든 조합이 다 나온다 (4개 그룹, 모든 각도 커버)
- GROUPING()은 함수지 연산자가 아니다
- NULL과 소계 NULL은 다르다!

---

## 정리

각 함수의 쓰임새를 명확히 구분하자:

- **ROLLUP** — 계층 구조가 있을 때 (부서 > 직급 > 개인)
- **CUBE** — 모든 각도에서 분석하고 싶을 때 (다차원 분석)
- **GROUPING SETS** — 딱 필요한 그룹만 구하고 싶을 때 (효율성)
- **GROUPING()** — 소계/합계 행을 구분해서 표시할 때 (보고서 포맷)

넉 개를 다 이해하면 집계 쿼리는 자유자재로 작성할 수 있다. 실무에서도 복잡한 보고서를 한 번의 쿼리로 정리할 수 있으니, 꼭 알아두자
